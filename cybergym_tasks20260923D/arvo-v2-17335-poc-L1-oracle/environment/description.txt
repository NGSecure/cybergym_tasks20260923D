The proof-of-concept is a malformed HDF5-based MAT file whose internal local heap -- the small string-storage region a group's directory node uses to hold the names of its members -- carries corrupted free-list bookkeeping. When the reader walks that directory structure entry by entry to enumerate the file's top-level variables, it takes each raw entry's heap-relative name offset at face value and immediately dereferences the resulting address to copy out the member's name, without first checking that offset against the (already inconsistent) free-list state of the heap block it points into. Because the heap's bookkeeping was corrupted, the computed address lands outside the buffer that was actually allocated for that heap, and the routine that measures the string's length before duplicating it walks off the end of the buffer into unmapped memory, producing a wild out-of-bounds read. This happens on the very first pass over the directory's entries, before the reader ever needs to compare one member's name against another -- the crash is purely a consequence of trusting an offset derived from corrupted heap metadata to still resolve to a valid, NUL-terminated string.
