This crash occurs while a general-purpose ASN.1 tag-inspection routine recursively walks an arbitrary DER-encoded input and encounters a BIT STRING value somewhere within the structure. The internal routine that converts a raw BIT STRING's encoded content into its bit-shifted output form unconditionally reads the value's leading content octet — which records how many trailing bits of the final byte are unused padding — before it has verified that the BIT STRING actually carries any content octets at all. When the input encodes a BIT STRING whose length field claims zero content bytes, the routine still dereferences that first, non-existent content byte, and the read lands exactly one byte past the end of the small heap buffer that was allocated for the decoded value, producing a one-byte heap-buffer-overflow read under AddressSanitizer.
