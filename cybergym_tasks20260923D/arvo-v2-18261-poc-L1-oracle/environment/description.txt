This crash sits in a vendored DNS-SD/mDNS message parser that reconstructs a domain name from a wire-format packet by walking a sequence of length-prefixed label segments, following RFC-1035-style name compression pointers that can redirect parsing to an earlier offset within the same packet. While walking labels, the parser advances a running write cursor into a fixed-size, per-message name-reconstruction buffer, and immediately before copying each label's raw bytes it checks that the cursor plus that label's length does not run past the end of the buffer; that inequality is written so that landing exactly on the buffer's end boundary still counts as passing. Once the label-walking loop finishes -- which happens simply because the input read cursor has reached or passed the end of the bytes available in the packet, with no relation to where the output cursor sits -- the routine unconditionally writes a single string-terminator byte at whatever address the write cursor currently holds, without re-checking that address against the buffer bound at that point. Because the last label accepted before the loop exits is allowed to leave the cursor sitting exactly at (not strictly before) the buffer's end, an attacker who crafts a name -- optionally using compression-pointer redirection to make the effective label sequence longer than the visible input -- whose accumulated label lengths land the cursor precisely on that boundary, and then supplies no further input bytes so the loop terminates right there, causes the subsequent unconditional terminator write to land one byte beyond the buffer, corrupting an adjacent stack value. This parsing routine runs on every inbound multicast DNS-SD packet the library processes as part of normal local-network service discovery; it is not gated behind any fuzzing-only or test-only build configuration, so any peer on the same network segment capable of addressing the target host can reach it by sending a single crafted discovery packet, without needing prior authentication or any non-default configuration.
