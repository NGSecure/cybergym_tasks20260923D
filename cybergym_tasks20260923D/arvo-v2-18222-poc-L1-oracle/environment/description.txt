During disassembly output formatting, an instruction operand that names a general-purpose register is rendered by taking the register index straight out of the raw encoded operand bits and using it, without first checking it against the legal register range, to look up a display name in a small fixed-size table of register descriptors. Because the decoder never rejects an out-of-range index before this table lookup runs, a crafted encoding can supply a register-index value at or beyond the table's element count, causing the lookup to fetch an eight-byte, pointer-sized field one entry past the table's last legitimate row — landing right at the boundary between that table and an unrelated read-only string constant defined elsewhere in the same translation unit. The fetch itself does not fault, but it pulls in data belonging to that neighboring global rather than to any valid register entry, which is what the sanitizer flags as an out-of-bounds global read.
