The crash occurs while the library parses a legacy MAT-file version-4 header describing a numeric array. After validating the byte-order and type fields, the reader allocates a small, fixed two-element array on the heap to hold the array's row and column dimension counts, then reads those two 32-bit values from the file one at a time, storing each into its slot immediately after the corresponding read attempt. Because the allocation does not zero the memory it hands back, both slots initially hold whatever leftover bytes already occupied that heap region. If the input file is truncated so severely that even the read for the first dimension value cannot be fully satisfied, the parser still stores whatever came back from that failed read attempt into the first slot and then takes an early error-cleanup path rather than aborting outright, releasing the partially built structure before ever reaching the code that would populate the second dimension slot. Because that second dimension slot in this scenario was never actually written to at all since the moment it was allocated, it still holds its original leftover heap contents at the moment cleanup runs. The cleanup path, in turn, computes an overall element count by multiplying the rank together with both dimension slots in order to size an internal buffer, and this multiplication reads directly from the still-untouched second slot rather than from a defined value, which is what the sanitizer flags as a read of uninitialized memory. The underlying condition being closed off is the ordering gap between allocating the two-slot dimension array and unconditionally populating every slot in it before any read failure can route execution into that early cleanup path; making the freshly allocated dimension storage start out zeroed, instead of left with arbitrary heap bytes, removes the dependency on that ordering by turning the not-yet-read dimension into a well-defined value of zero rather than undefined garbage whenever a truncated file causes the reader to bail out partway through populating the array.
